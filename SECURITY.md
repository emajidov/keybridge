# Security Policy

KeyBridge uses macOS Accessibility access to read and rewrite keyboard events. It does not store or send anything you type, and it makes no network connections.

If you find a security problem, please **don't open a public issue**. Report it privately with [GitHub's private vulnerability reporting](https://github.com/emajidov/keybridge/security/advisories/new) or email majidov.elgun@gmail.com. I'll reply as soon as I can.
